# 💼 Мониторинг и парсер вакансий в РФ («Работа России»)

[![Python](https://shields.io)](https://python.org)
[![Streamlit](https://shields.io)](https://streamlit.io)
[![Altair](https://shields.io)](https://github.io)
[![License: AGPL v3](https://shields.io)](https://gnu.org)

Интерактивное веб-приложение на базе **Streamlit** для сбора, фильтрации, визуализации и экспорта актуальных вакансий из единой цифровой платформы **«Работа России»** (`opendata.trudvsem.ru`).

---

## ✨ Основные возможности

* **Прямой сбор данных через официальное API:** Получение актуальных вакансий по любому ключевому запросу без необходимости парсинга HTML-страниц.
* **Гибкая фильтрация и сортировка:**
  * Фильтр по конкретному региону или городу с отображением количества доступных предложений.
  * Отбор только тех вакансий, где указана заработная плата.
  * Сортировка результатов по возрастанию или убыванию стартовой зарплаты.
* **Сводные KPI-метрики:** Мгновенный расчет общего числа найденных вакансий, количества уникальных регионов и средней стартовой зарплаты по выборке.
* **Интерактивная визуализация (Altair):**
  * **Топ-10 регионов** по количеству открытых вакансий.
  * **Топ-10 регионов** по среднему уровню стартовой зарплаты (в рублях).
  * Распределение вакансий по **типу занятости**.
  * Рейтинг **топ-7 работодателей** по числу предложений.
* **Экспорт данных:** Выгрузка отфильтрованной таблицы в формате **CSV** (с кодировкой `UTF-8-SIG` для корректного открытия в Microsoft Excel).

---

## 🛠 Технологический стек

* **Python 3.10+** — основной язык разработки.
* **Streamlit** — фреймворк для создания интерактивного веб-интерфейса и управления состоянием сессии (`st.session_state`).
* **Requests** — выполнение HTTP-запросов к API с обработкой таймаутов, лимитов (`HTTP 429`) и повторными попытками.
* **Pandas** — очистка, трансформация и агрегация данных.
* **Altair** — построение декларативных интерактивных диаграмм со строгой фиксацией осей.

## 🚀 Быстрый старт (локальный запуск)

### 1. Клонируйте репозиторий
```bash
git clone https://github.com<ваш-логин>/<название-репозитория>.git
cd <название-репозитория>
```

### 2. Создайте и активируйте виртуальное окружение
**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Запустите приложение
```bash
streamlit run app.py
```
После запуска приложение автоматически откроется в браузере по адресу `http://localhost:8501`.

## ☁️ Бесплатный деплой в облако (Streamlit Community Cloud)

Вы можете развернуть приложение в интернете бесплатно за пару минут:

1. Загрузите файлы `app.py` и `requirements.txt` в публичный репозиторий на GitHub.
2. Перейдите на [share.streamlit.io](https://streamlit.io) и авторизуйтесь через GitHub.
3. Нажмите **Create app** → выберите ваш репозиторий, ветку `main` и главный файл `app.py`.
4. Нажмите **Deploy** — через 1–2 минуты приложение станет доступно по постоянной публичной ссылке.

## ⚠️ Примечания по работе с API

* Используется открытый эндпоинт `http://trudvsem.ru`.
* В приложение встроено кэширование запросов (`@st.cache_data(ttl=600)`) на **10 минут**, что ускоряет работу интерфейса и снижает нагрузку на государственный портал.
* При возникновении ошибки `429 Too Many Requests` скрипт автоматически выполняет серию повторных запросов с экспоненциальной задержкой.
